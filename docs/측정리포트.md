# AI 기능 실측 리포트

RTL-M 핵심 10번(AI 추천/상담)의 "추천 API 의 응답시간·정확도 측정 결과 문서화"에 해당한다.
측정 스크립트는 `scripts/measure_ai.py`, 종단 기능 검증은 `scripts/verify_omni.py`.

## 측정 환경

- 2026-08-18, 로컬 기동(인프라 컨테이너 7종 + 서비스 jar 8종), 게이트웨이(:8000) 경유
- LLM: gpt-4o-mini 실경로 (전 측정에서 폴백 0회)
- 상품 데이터 490건 (직접 수집, 식약처 공공데이터 대조)

## 1. 추천 API 응답시간

행동 기반 추천 조회(`GET /recommendation-service/recommendations/{memberId}`) 30회 연속 호출.

| avg | p50 | p95 | max |
|---|---|---|---|
| 530ms | 512ms | 686ms | 774ms |

## 2. 챗봇 응답시간·정확도 (LLM 실경로)

자연어 질의 5문항. 정확도는 반환 상품의 상세를 재조회해
질의 조건(제외 감미료 미포함, 가격 상한, 카테고리)과 대조하는 방식으로 판정했다.

| 질의 | 응답시간 | 반환 | 조건 부합 |
|---|---|---|---|
| 아스파탐 안 들어간 콜라 | 1,949ms | 3건 | 2건 |
| 1만원 이하 저당 아이스크림 | 2,789ms | 0건 | - |
| 말티톨 없는 제로 초콜릿 | 1,361ms | 3건 | 3건 |
| 수크랄로스 빼고 제로 음료 추천해줘 | 1,703ms | 3건 | 3건 |
| 5천원 이하 제로 과자 | 1,495ms | 3건 | 0건* |

- 응답시간 avg 1,859ms / max 2,789ms
- 반환 상품 기준 조건 부합률 8/9 (89%)
- *5번 문항의 반환 3건은 가격 조건(5천원 이하)을 초과 — 파서가 가격 상한을 하드필터가 아닌
  선호 조건으로 전달한 케이스. 2번 문항의 0건은 해당 조건을 전부 만족하는 상품이 데이터에 없는 경우로 정상 동작.

## 3. 자연어 검색 응답시간

`POST /recommendation-service/search` 3문항.

| 질의 | 응답시간 | 결과 |
|---|---|---|
| 말티톨 없는 제로 초콜릿 | 1,582ms | 11건 |
| 아스파탐 없는 음료 | 1,518ms | 230건 |
| 1만원 이하 저당 과자 | 2,069ms | 0건 |

avg 1,723ms. 조건 추출과 하드필터가 분리되어 있어 결과 0건도 필터 동작으로는 정상이다.

## 4. LLM 장애 폴백

LLM 키 없이 기동한 검증 회차에서 전 챗봇 요청이 규칙 파서 응답(`usedFallback=true`)으로
전환됨을 확인했다. 폴백 시 응답에 "규칙 기반 응답" 표시가 붙는다. 키 주입 기동에서는 폴백 0회.

## 5. 부하 테스트 (k6)

추천 API 대상, 30 VU, 총 2,044 요청 (`loadtest/reco-load.js`, 결과 `loadtest/summary*.json` 3회분).

| 처리율 | avg | p50 | p95 | max | 실패율 |
|---|---|---|---|---|---|
| 16.9 req/s | 1,164ms | 710ms | 3,668ms | 7,756ms | 0% |

부하 상황(p95 3.7초)은 단건 측정(p95 0.7초)보다 크게 느려진다. H2 인메모리 단일 인스턴스
구성의 한계로, 개선 여지는 추천 결과 캐시와 인스턴스 증설이다.
